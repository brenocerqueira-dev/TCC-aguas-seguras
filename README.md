## 📖 Sobre o Projeto

O **Águas Seguras** é um projeto de Trabalho de Conclusão de Curso (TCC) desenvolvido no curso Técnico em Automação Industrial pelo **SENAI Dendezeiros**. 

O objetivo do projeto é desenvolver uma solução tecnológica automatizada, acessível e economicamente viável para auxiliar no monitoramento da poluição marinha. O sistema realiza a aquisição de parâmetros de qualidade da água (pH e turbidez) e disponibiliza as informações em uma plataforma digital.

Este repositório contém o **Modelo 3D conceitual e interativo** do equipamento, construído inteiramente para a web, permitindo a visualização em 360º de todos os componentes de hardware utilizados na solução.

## ✨ Funcionalidades da Aplicação Web

- **Visualização 3D Interativa:** Arraste para girar, use o scroll/pinça para aproximar e explore o modelo de todos os ângulos.
- **Painel de Controles 3D:**
  - Ocultar/Exibir cobertura e tampa.
  - Vista explodida para visualizar detalhes internos.
  - Câmeras pré-definidas (Vista Superior e Frontal).
  - Rotação automática.
- **Foco em Componentes:** Clique em itens na lista lateral para que a câmera dê um zoom automático no componente específico dentro do modelo 3D.
- **Design Responsivo:** Interface adaptada para funcionar perfeitamente tanto em computadores quanto em dispositivos móveis.

## 🛠️ Componentes do Sistema (Hardware)

O modelo digital ilustra a integração dos seguintes componentes:
- **Microcontrolador:** ESP32 DevKit
- **Sensores:** Sensor de pH (PH-4502C) com eletrodo e Sensor de Turbidez (ST100)
- **Estrutura:** Caixa organizadora (29L) e recipiente de teste de acrílico/vidro.
- **Eletrônica Auxiliar:** Protoboard MB-102, módulos de leitura, resistores e jumpers.
- **Alimentação:** Fonte 5V / 2A (Micro USB).

> **Nota:** As dimensões, alturas e posições no modelo 3D são ilustrativas. O equipamento representado é um modelo conceitual.
